## Explicit external blockers

- Provider connection, balance, service fetch, submit, and status UAT require a real provider URL/key.
- Casso/Binance webhook acceptance requires merchant credentials and signed external callbacks.
- SMTP delivery and production object storage require operator infrastructure.
- Browser authentication E2E requires Chromium/Playwright plus a running migrated PostgreSQL/Redis stack.

No control in the matrix is counted as a live-integration pass based solely on a mocked adapter.
